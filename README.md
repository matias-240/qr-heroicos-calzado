# qr-heroicos-calzado

Páginas de redirección para los QR de «Heroicos copia_v9.pdf»: heroicos de calzado de 400x620 mm, una hoja por modelo.
Cada QR apunta a `/pagNN/` (la hoja del PDF), que redirige a https://www.falabella.com/falabella-cl.

Para cambiar el destino de un QR, reemplaza la URL en `pagNN/index.html` (aparece cuatro veces).
